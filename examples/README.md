# examples

Standalone, no-SDL programs that exercise libtcod APIs from the terminal. Unlike
`samples/` (which open a tcod console window), these print plain ASCII to stdout, so
they build and run anywhere and are easy to read in a code review.

## pathfinding_heuristics_demo.c

An explainer for the custom-heuristic / weighted-A* / multi-root-Dijkstra additions to
the pathfinder. Five scenes, each prints a grid and some numbers:

1. **Heuristics shrink the search** — the same optimal path found with ZERO (= Dijkstra),
   Euclidean, Manhattan, and weighted Manhattan, with the count of cells opened collapsing
   as the heuristic tightens. Side-by-side frontier maps make it visual.
2. **Variable terrain cost** — a walk-cost callback ("avoid the bog, cross it if it's
   worth it") paired with a heuristic via `TCOD_path_new_using_function_ex`. Compares the
   terrain-aware path against a terrain-blind shortest path.
3. **Domain heuristic / preferred route** — a custom, deliberately inadmissible heuristic
   (`dist-to-goal + penalty * dist-to-corridor`) steers A* to hug a precomputed waypoint
   corridor instead of the geometric shortest line.
4. **Voronoi terrain** — terrain generated by the *existing* `TCOD_heightmap_add_voronoi`,
   thresholded into cost bands and crossed by cost-aware A* (no custom Voronoi code).
5. **Landmark / ALT heuristic** — distances precomputed from a few landmarks with the
   *existing* `TCOD_dijkstra` give a tighter admissible heuristic than straight-line; on a
   concave-trap map the straight-line search floods the dead end while ALT skips it.

Scenes 2 and 4 also show why a heuristic carries its own `user_data` separate from the
walk-cost callback: the cost function and the (instrumenting) heuristic need different
contexts, set via `TCOD_path_set_heuristic(path, func, user_data, weight)`.

### Build & run

From the repository root, against a libtcod build of this branch:

```sh
clang -std=c11 -O2 examples/pathfinding_heuristics_demo.c -I src \
    -L <build-dir> -ltcod -lm -Wl,-rpath,<build-dir> -o pfdemo
./pfdemo
```
